# دَيْني — إدارة الديون

تطبيق Flutter عربي (RTL) لإدارة الديون التي عليك، وتسجيل الدفعات، ومتابعة الرصيد المتبقي، وإنشاء تقرير PDF.

## المزايا
- لوحة ملخص: إجمالي الديون، المدفوع، والمتبقي.
- إضافة وتعديل وحذف دين مع اسم الجهة والمبلغ وتاريخ الاستحقاق وملاحظات.
- تسجيل دفعات جزئية أو كاملة مع سجل لكل دين.
- حالات واضحة: غير مسدد، مسدد جزئياً، مسدد.
- بحث وفرز وعرض الديون.
- تصدير تقرير PDF ومشاركته أو طباعته.
- تخزين محلي على الجهاز باستخدام SQLite.
- اختيار العملة من الإعدادات (الافتراضي USD).

## التشغيل
1. ثبّت Flutter SDK وأضفه إلى PATH.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ:

```bash
flutter pub get
flutter run
```

## إنشاء ملفات المنصات
يتضمن هذا المستودع ملفات التطبيق الأساسية الجاهزة. إذا لم تتوفر مجلدات `android/` أو `ios/` في النسخة التي لديك، أنشئ ملفات المنصات مرة واحدة من داخل مجلد المشروع:

```bash
flutter create --platforms=android,ios,web,windows,linux,macos .
flutter pub get
flutter run
```

لإنشاء APK:

```bash
flutter build apk --release
```

ستجد الناتج في:
`build/app/outputs/flutter-apk/app-release.apk`

## ملاحظات
- البيانات محفوظة محلياً على الجهاز ولا يتم إرسالها إلى خادم.
- تصدير PDF يستخدم خطوط النظام الافتراضية؛ قد تحتاج إضافة خط عربي مضمّن للمظهر المثالي للنص العربي في جميع الأجهزة.
- قبل النشر، اختبر إنشاء PDF على جهاز Android فعلي.
